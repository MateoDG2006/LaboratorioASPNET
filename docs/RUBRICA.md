# Evidencias para la rúbrica

| Criterio | Peso | Implementación | Evidencia a capturar |
| --- | --- | --- | --- |
| Puntualidad | 15 % | Entrega del estudiante | Comprobante dentro del plazo indicado, 23 de noviembre de 2026. |
| CREATE | 10 % | Formulario crear, servicio y sp_create | Usuario nuevo en pantalla y en MySQL. |
| READ | 20 % | GridView, detalle, sp_load y sp_read | Listado y detalle de dos IDs diferentes. |
| UPDATE | 20 % | Formulario editar y sp_update | Antes y después del mismo registro; fecha de modificación. |
| DELETE | 20 % | Confirmación y sp_delete | Desaparición del listado activo y permanencia del historial con fecha de eliminación. |
| Repositorio y documentación virtual | 15 % | Solución, README, Database y docs | Enlace accesible, SQL y guía de preparación. |

## Conceptos del material aplicados

- Proyecto ASP.NET Web Forms con .NET Framework 4.7.2 y MySQL.
- Master Page y ContentPlaceHolder para compartir la estructura.
- TextBox, Button y GridView con `runat="server"`.
- Carga inicial con `!IsPostBack`.
- Identificador por `Request.QueryString` y `CommandArgument` enlazado a cada fila.
- Cadenas mediante `ConfigurationManager` y conector `MySql.Data`.
- Procedimientos almacenados con parámetros tipados.
- Fechas de inserción, modificación y eliminación lógica.
- HTML, CSS, metadatos y Bootstrap para la interfaz.
- Biblioteca de clases para separar reglas y acceso a datos.

La rúbrica suministrada no asigna porcentajes separados a componentes visuales específicos. El proyecto utiliza los recursos que apoyan el flujo; no incorpora componentes sin función solo por aparecer en un PPT.

## Antes de enviar

1. Sustituir la identificación académica si se solicita portada o nombre en el informe.
2. Capturar las evidencias de `PRUEBAS.md` en el equipo donde se presente.
3. Confirmar que no se incluye Conexion.local.config ni una contraseña real.
4. Subir los fuentes a un repositorio y comprobar el acceso de la docente.
5. Conservar el comprobante de envío. El código preparado no acredita puntualidad por sí solo.
